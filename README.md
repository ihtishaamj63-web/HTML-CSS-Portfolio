## 📖 About this project

This portfolio is a milestone in my journey to becoming a full‑stack developer.  
It brings together everything I've learned at Life Choices Academy: semantic HTML, modern CSS, responsive design, and clean layout principles — all without using JavaScript.

It includes sections about my background (BSc in Biodiversity & Conservation Biology, first‑in‑class at Pelican Park High), my current training, my projects (Python Mini Toolkit and JavaScript Calculator), and a working contact form.

---

## ✨ Features

- 🧭 **5 pages:** Home, About, Projects, Education, Contact  
- 🎨 Modern, readable colour palette (navy & deep teal)  
- 📱 Fully responsive — works on phones, tablets, and desktops  
- 🖼️ Image placeholders ready for my actual portrait  
- 📬 A live contact form powered by Formspree  
- ♿ Accessibility basics: skip link, semantic tags, alt text  
- 📄 Clean, commented, and well‑structured code  

---

## 🛠️ Built with

- HTML5 (semantic elements, tables, forms)  
- CSS3 (Flexbox, Grid, variables, media queries, transitions)  
- Google Fonts (Inter & Poppins)  
- Formspree for the contact form
